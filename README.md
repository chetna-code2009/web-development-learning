## 🚀 How to Run

### Option 1 — Open Directly

1. Download or clone this repository.
2. Open the folder.
3. Double-click any `.html` file.
4. The webpage will open in your default browser.

### Option 2 — Using VS Code

1. Open the repository in **Visual Studio Code**.
2. Open any HTML file.
3. Run it using a browser.
4. The `krishna.html` file should be kept in the same folder as `krishna_flute.mp3` so that the audio works correctly.
